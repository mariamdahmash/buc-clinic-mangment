# لوحة الإدارة

- `/login`: تسجيل الدخول.
- `/super-admin`: إنشاء عيادة وحساب مديرها، عرض رابط الموقع، تفعيل/تعطيل العيادة.
- `/clinic-admin`: التخصصات والدكاترة والخدمات وجداول العمل والحجوزات.
- `/<slug>`: صفحة العيادة وحجز المواعيد.

كل فترة عمل مرتبطة بتاريخ محدد. اختَر مدة الكشف لتقسيم الفترة إلى أوقات قابلة للحجز. إلغاء الحجز يتيح الوقت مرة أخرى. لا يمكن حذف تخصص مرتبط بأطباء أو خدمات، ولا تعديل فترة عليها حجوزات فعالة قبل نقلها أو إلغائها.

تعليمات التشغيل والمتغيرات ومتطلبات MongoDB موجودة في README.md الرئيسي.
